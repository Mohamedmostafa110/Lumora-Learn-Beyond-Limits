What happens if Redis fails halfway through a snapshot rebuild from Kafka? Does consumer offset roll back automatically?

AV
Alex Vance (Instructor)

Great question Tarek. Offsets are committed manually only after Redis returns the transaction OK acknowledgment. If Redis dies, the next consumer rebalance replays from the last committed offset.
